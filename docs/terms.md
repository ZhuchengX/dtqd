## 1. 软件性质

本软件是在你设备上运行的桌面应用，用于汇总校园信息、编辑文档、运行终端，以及调用人工智能 Agent。本软件没有账号系统，**发布方不运营存放你数据的服务器，也不托管任何大模型**。

**数据保存在本机不等于不离开本机。** 你的内容会依《隐私条款》的说明发送给你配置的模型服务及其他第三方服务；你主动提交反馈时，反馈内容会发送给发布方。除此以外，发布方不接收你的数据。

Agent 使用的大模型能力来自你自行选择和配置的第三方模型服务。

**本机扫描（不联网）：** 本软件会查看本机 QQ 接收文件夹中的新文件名和时间（可在 设置 › 重要事项 关闭）。Agent 在你提问时也可以列出和读取 QQ、微信接收文件夹中的文件。这些操作不读取聊天记录，也不解密聊天数据库。文件正文只有在 Agent 读取时才会发给模型服务。

**后台运行：** 关闭窗口只是把本软件收进托盘，同步继续进行。要完全停止，请关闭「自动同步」或从托盘菜单退出。

**更新：** 本软件暂无应用内更新，不会访问任何更新服务器。新版本需从发布方的 GitHub Releases 下载。

**上游功能：** 交大专属功能（Canvas、水源、交大视频和课表）默认隐藏。只有你在设置中开启并配置后，才会访问 sjtu.edu.cn 的相关地址。
