# DTQD 隐私条款

最后更新：2026-11-02

本条款由长沙邓途启迪科技有限公司（下称「发布方」）提供，说明 DTQD 桌面软件（下称「本软件」）在你设备上保存什么、哪些内容会离开你的设备、发给谁，以及你如何控制。联系方式见第 9 节。

## 1. 数据保存在本机

**发布方不运营存放你数据的服务器，也不接收你的数据，第 7 节的反馈除外。** 你的对话、资料与各项设置都保存在你的设备上。

应用数据目录（macOS 上通常是「~/Library/Application Support/DTQD」，Windows 上通常是 %APPDATA%\DTQD）下：

- SQLite 数据库 dela.db：会话索引、邮件与课程等同步数据、笔记与文件的索引、校内通知存档、通知、各项设置，以及条款接受记录（哪一份、哪一版的条款，以及接受时间与应用版本）。
- 对话的完整记录：pi/sessions 下的 JSONL 文件，由 Agent 内核写入；数据库里只有这些会话的索引。
- 其他文件：对话中发送的图片与文档附件副本（chat-media/）、邮件草稿（mail-drafts/）、远端项目的内容镜像（remote-context/）。文档副本保留供后续追问，启动时清理没有会话引用的图片与文档；未发送的文档附件在你移除时删除。
- 界面状态：Chromium 的 Local Storage 里存着侧栏与各面板的折叠状态和宽度、主题与字号、聊天草稿，以及引导步骤与你同意的条款版本。
- 你主动导出的备份：在条款接受页选择位置后，主进程把应用数据、工作目录与你自己的 Skill 复制过去。这是一次本地文件复制，不联网；副本里含有凭据文件与数据库，请保存到你信任的位置。

同一目录下的加密凭据文件：

| 凭据文件             | 保存的内容                                              |
| -------------------- | ------------------------------------------------------- |
| llm-providers.bin    | 模型服务地址与 API Key                                  |
| mail-credentials.bin | 邮箱地址与密码                                          |
| teams-session.bin    | Microsoft、Teams、Outlook 与邓迪登录页的 session Cookie |
| campus-session.bin   | 校园登录窗口的 session Cookie（myDundee、中南教务等）   |

只有在你开启上游交大功能并配置后，才会另有 canvas-token.bin 和 shuiyuan-key.bin。

工作目录（默认「文档/DTQD」，本机已有「文档/Dela」的沿用旧目录，可在 设置 › 工作区 更改）中的文件：笔记的 Markdown 正文与其中的图片、导入的文件、从 myDundee 下载的课程文件（courses/），以及导出到「预览导出」文件夹的 PDF。

重要事项与校园连接还会在本机保存以下内容，**这些内容含他人发言和姓名，且未单独加密**：

- Teams 消息存档：工作目录的 teams/ 文件夹，按会话保存为 Markdown，包括频道、群聊、会议聊天和私聊；
- Outlook 网页版收件箱列表（发件人、主题、预览）：保存在本地数据库；
- 重要事项文件：工作目录的「重要事项」文件夹，含提取结果和提取失败时等待重试的内容（.pending.json）；
- 校内通知存档：保存在本机，供聊天问答使用；
- 未发送成功的反馈：feedback-queue.json，发送成功后清除。

**如果你的「文稿」文件夹开启了 iCloud 或其他云同步，工作目录中的上述文件可能被同步到云端。** 如不希望如此，请在 设置 › 工作区 把工作目录改到未同步的位置。

Teams 和校园登录窗口的页面数据（含持久 Cookie 和 Teams 本地缓存）由内置浏览器组件保存在应用数据目录。其保护程度取决于系统账户安全，请勿与他人共用系统账户。

开启 Pi packages 时：登记的包（来源、启停、资源开关）存在数据库里；从 npm 或 git 安装的包在应用数据目录的 pi/npm 与 pi/git 下，本地目录来源不复制、只登记路径；本机没有 npm 时下载的 Node 运行时在 components/node 下；包注册的 MCP 服务器的连接日志在 pi/mcp.log。本软件 不读写你自己的 ~/.pi 目录，只有一个例外：包注册的、需要 OAuth 登录的 HTTP MCP 服务器，其登录凭据由 Pi 存在 ~/.pi/agent/mcp-auth.json。

可选文档解析组件保存在应用数据目录的 components/document-reading 下。文档读取任务的输入副本与提取结果保存在系统临时目录的 dela-document-reading 下，读取结束后清理；异常退出留下的任务会在下次准备文档时清理超过 24 小时的部分。

邮件、课程、课表与作业是学校服务的本地副本，可重新同步获取。邮箱密码不写入数据库：数据库里只有邮箱地址、服务器与端口。

## 2. 凭据如何保护

- **凭据文件用 Electron safeStorage 加密后写入，解密能力由操作系统保管**；系统不支持加密时，应用拒绝读写并给出提示。
- 写入先落临时文件再原子替换；旧文件无法解密时，先备份为「原文件名.unreadable-随机串.bak」再写入新内容，不因重新配置而删除。
- **API Key 与令牌只在主进程内使用**：界面拿到的模型服务配置不含密钥字段；邮箱只返回连接状态、邮箱地址或用户名，不含密码与令牌。
- **密钥不进入模型消息**：请求时由主进程把 API Key 放进 HTTP 请求头，发给模型的内容是对话与资料文本。

## 3. 发送到模型服务的内容

本软件在两种情况下请求模型服务：（一）你发送消息、让 Agent 继续执行或检测密钥；（二）**你开启「重要事项 AI 提取」后，有新内容时自动发送，最多每 30 分钟一次，无需你每次操作。该功能默认关闭，你可以随时关闭。关闭后，尚未发送的内容不再发送，但已经发送的内容无法撤回。**

运行 Agent 时发送的内容：

- 系统提示词，以及已启用 Skills 的名称与描述索引。
- 你在 设置 › 自定义指令 中填写的全局指令（留空则不发送），它会随每次请求一并发出。
- 当前会话的历史消息；较早历史已生成摘要时，摘要一并发送。
- 本轮引用的资料内容（按需读取的笔记、课程文件、邮件等正文）、附件正文、你输入的文字与图片。
- 工具执行结果会随后续轮次继续发回同一服务。

重要事项提取发送的内容（可在 设置 › 重要事项 按来源关闭）：Teams 频道和群聊消息，含会议聊天（单条最多 4,000 字；私聊需另外开启）；Outlook 网页版的发件人、主题和预览，或 IMAP 邮件正文（单封最多 1,500 字）；myDundee 公告；校园通知（你开启校内办公网后也包括其通知）；QQ 接收文件的文件名和时间；你的在读课程和关心方向。首次开启时，最多回看最近约 14 天尚未处理的内容。

这些内容发往 设置 › 模型供应商 中启用的地址。**数据保存在本机不等于在本机推理**：应答由你选择的模型服务产生，内容发出后如何保存由该服务决定，本软件不控制。

### 3.1 他人的信息

邮件、Teams 消息和文件中可能含老师、同学及其他人的姓名、联系方式和发言。这些人没有直接同意过本软件的处理。请你：

- 只在个人学习和个人事务所需范围内使用这些内容；
- 不要公开、转发或向无关人员提供；
- 涉及他人隐私的内容，不要让 Agent 读取；如果有私聊不宜发送，请保持「私聊进入提取」关闭。

如你认为本软件的功能设计影响了你的权益（包括你是老师或同学，而不是本软件的使用者），可通过第 9 节的方式联系发布方。发布方无法查看或删除保存在用户设备上或模型服务处的内容，但会评估并调整相应功能。

### 3.2 成绩与敏感信息

你让 Agent 查询成绩、读取课件或处理文件时，相关内容会发给模型服务。

**使用 MC / Extension 申请辅导时，病历、诊断等健康信息属于敏感个人信息，一旦泄露可能对你造成较大影响。把这些内容提供给 Agent，即会发送给你配置的模型服务。请只提供必要内容，并尽量隐去身份证号、住址等无关信息。发布方不接收这些内容。**

### 3.3 模型服务及其所在地

模型服务由你选择，其运营者、数据存储地、留存期限和是否用于训练，以该服务的条款为准；开启前请自行阅读。本软件的预设服务（DeepSeek、MiniMax、智谱）使用境内接口地址。**如果你通过「自定义」配置境外服务，你的内容（可能含他人信息）将发往境外，由此产生的义务和风险由你自行评估。不确定时，请使用境内服务。**

**本机扫描（不联网）：** 本软件会查看本机 QQ 接收文件夹中的新文件名和时间（可在 设置 › 重要事项 关闭）。Agent 在你提问时也可以列出和读取 QQ、微信接收文件夹中的文件。这些操作不读取聊天记录，也不解密聊天数据库。文件正文只有在 Agent 读取时才会发给模型服务。

**后台运行：** 关闭窗口只是把本软件收进托盘，同步继续进行。要完全停止，请关闭「自动同步」或从托盘菜单退出。

**更新：** 本软件暂无应用内更新，不会访问任何更新服务器。新版本需从发布方的 GitHub Releases 下载。

**上游功能：** 交大专属功能（Canvas、水源、交大视频和课表）默认隐藏。只有你在设置中开启并配置后，才会访问 sjtu.edu.cn 的相关地址。

**已启用的 Pi package 不受上述清单约束**。包里的扩展与本软件同进程、同权限运行，能读到本机文件、数据库与解密后的凭据，可以自行联网，它发出什么、发往哪里由包作者决定，本软件不代理、不记录也不拦截。是否启用一个包，请先确认它的来源与源码。

## 5. 本机记录了什么

**应用运行时不写日志文件**（开发模式的控制台输出只打印在终端，不落盘）。Agent 执行也不单独留档：一次执行的运行状态只存在于内存与界面（导航行上的运行标记），执行过程随对话正文一起写进会话文件（见第 1 节），数据库里的会话索引只记消息计数与最后更新时间。

凭据与密钥不写进会话记录，也不会作为上下文发给模型。

## 6. 本软件没有的功能

- 没有账号服务器：不需要注册或登录 DTQD 账号；
- 没有云同步：本软件不提供云同步；
- 没有使用统计和崩溃上报。

## 7. 反馈

**你点击发送反馈时，下列内容会发送到发布方团队的飞书群：反馈正文、你所在的页面、软件版本和时间。** 发布方用于改进产品和回复问题，并仅限团队内需要处理反馈的人员查看。飞书由其运营者提供服务。

反馈发送失败时暂存在本机，下次发送时补发。**请不要在反馈中填写姓名、学号、成绩、账号、密码或他人信息。** 发布方将反馈保存不超过 12 个月，之后删除；你可以按第 9 节要求删除。

## 8. 未成年人

如你未满 18 周岁，建议在监护人指导下使用。**未满 14 周岁的，必须由监护人阅读并同意本条款后方可使用。** 请合理安排使用时间，不要过度依赖 AI。

个人信息处理者：长沙邓途启迪科技有限公司。联系方式：应用内「反馈」。反馈内容不公开；需要答复时，请在反馈中留下你希望使用的联系方式。

- **本机数据：** 你可以在本软件中查看、修改，或删除应用数据目录和工作目录，自行行使删除权。发布方无法访问这些数据。

- **规则变更：** 处理目的、方式或种类发生变化时，发布方会更新本条款，并在下次打开新版本时请你重新确认。
