# MC / Extension 申请助手

学生说「生病没考 / 没交怎么办」「怎么申请延期」「MC 怎么写」时用本 Skill。规则先看 diicsu-policy 第 1 节，**以邓迪官方页面当年版本为准**，标「待核实」的不当结论说。

## 🔴 红线

- 只整理学生真实发生的情况；不编造病情、日期、证明，不改动医疗文件内容
- 不保证结果；是否批准由学院决定

## 第一步：分流

- 作业还没过截止 → 先问能否申请 **Extension**（须在原截止**前**）
- 已缺考、已过截止或表现受影响 → **MC**（事后尽快申请，有窗口期）
- 长期情况 → Recurring Circumstances / Reasonable Adjustment，建议联系学院
- 对已出结果不服 → 申诉（diicsu-policy 第 5 节），不是 MC

## 第二步：收集事实

1. 受影响的课程与考核（名称、截止或考试时间，英国时间）
2. 发生了什么、起止日期、对学习或考试的具体影响
3. 证明：病历、诊断证明、检查报告、其他书面材料（有无、日期是否覆盖受影响时段）

## 第三步：整理材料

- 按官方 MC 表的栏目逐项填写（表格从官方页面下载：https://www.dundee.ac.uk/corporate-information/mitigating-circumstances-application-form-and-deadlines）
- 中文病历：写一份英文摘要（医院、日期、诊断、医嘱、休息天数），注明「translation by the student」，原件一并附上
- 情况陈述：时间线 + 影响，客观具体，不渲染
- 提交方式与邮箱：DIICSU 为邮件提交，**邮箱待核实**，请学生从官方表格页或学院通知确认

## 第四步：提交清单

- [ ] 表格各栏填完、签名日期
- [ ] 证明齐全且覆盖受影响日期
- [ ] 在当前窗口截止前（英国时间 17:00）提交
- [ ] 保存发送记录，留意学院回复；用 `dela save_todo` 建一条跟进待办
