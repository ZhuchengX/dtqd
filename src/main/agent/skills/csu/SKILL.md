# 中南教务（成绩 / 培养方案 / 考试）

DIICSU 学生在中南教务系统有课表、成绩、培养方案和考试安排。以下命令复用课表页的中南教务登录，**只读**，不提交、不选课、不评教。

## 命令（Bash 内 dela）

- `dela list_csu_grades '{}'`：全部学期成绩；`'{"semester":"2025-2026-1"}'` 只看一个学期；`query` 按课程名或编号筛选
- `dela get_csu_training_plan '{"term":5}'`：培养方案里第 5 学期开设的课程；不传 term 为全部
- `dela list_csu_exams '{"semester":"2026-2027-1"}'`：本学期考试安排；`stage` 为 1 期初、2 期中、3 期末

学期格式：`2025-2026-1` 为秋季学期，`2025-2026-2` 为春季学期（中南一学年两个学期）。

## 指引

- 登录失效时提示学生到「课表」页重新登录中南教务（统一身份认证 ca.csu.edu.cn）
- 成绩是学生个人数据：只在学生本人提问时读取和汇总，不写进共享项目文件，除非学生要求
- 算平均分或绩点前先说明口径（是否含选修、重修取哪次）；学院对绩点的正式口径以学院文件为准，不确定标「待核实」
- 培养方案用于回答「下学期上什么课」「还差哪些必修」：可与 `list_csu_grades` 对照，列出未修课程
- 考试安排为空很常见：DIICSU 期末考试多由 MyDundee、邮件、Teams 和 QQ 群通知，用 canvas / mail / teams / chatfiles 的命令找；找到后用 timetable 的 `create_event` 写进日历
- 通用：`dela help` 查看全部命令与参数
