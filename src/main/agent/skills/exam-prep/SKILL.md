# 考试倒计时与复习计划

学生说「快考试了帮我排复习」「我还有几天」「把考试时间加进日历」时用本 Skill。

## 步骤

1. 收集每科考试：课程、日期时间（注明英国时间还是北京时间；邓迪侧一律按英国时间换算）、形式（闭卷 / 开卷 / 线上）、范围
   - 可用 `dela query_assignments`、`dela query_schedule` 查已有信息；拿不到的问学生，不猜
2. 每科建一条待办：`dela save_todo`，标题「考试：课程名」，截止 = 考试开始时间，备注写地点与范围（截止前 3 天 / 1 天 / 3 小时会自动提醒）
3. 倒排复习：从今天到考前一天，按「难度 × 学分 ÷ 剩余天数」分配，每块 60–90 分钟，避开课表上的课
4. 复习块用 `dela create_event` 写入日历，标题「复习：课程 · 主题」
5. 每块写清这一块要完成什么（读完第 3 章并做往年题 2 道），而不是「复习数学」

## 原则

- 先列出今天要做的第一块，让学生马上能开始
- 每天留空档；考前一天只做回顾与错题
- 学生说进度落后时，重排剩余天数，砍掉低优先级内容，不要只是往后推
- 复习方法配合 study-coach（讲思路、出练习、查错），往年题可用 canvas 查找
