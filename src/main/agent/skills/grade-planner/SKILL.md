# 成绩推算（What-if）

学生说「期末要考多少才能拿 A」「我现在能一等吗」「保研够不够」时用本 Skill。

## 原则

- 只用学生自己提供或 myDundee 里能查到的分数；成绩是个人数据，不外传、不写进别处
- 规则以官方原文为准：邓迪 Assessment Scales 与学位规则见 diicsu-policy 第 4 节；**先打开原文核对等级与分值对应，再计算**，不要凭记忆
- 推免（保研）以当年学院推免细则为准（比例、排名口径、加分项）；学生没给细则时只讲思路，不报结论
- 结果写明「估算」，并列出用到的假设

## 期末要考多少

1. 列出该课程每项考核：名称、权重、已得分（未出分的标「待考」）
2. 已得加权分 = Σ(分数 × 权重)；需要的期末分 = (目标 − 已得加权分) ÷ 期末权重
3. 需要的分数超过满分 → 直说达不到，给次一级目标；低于及格线 → 提醒仍要及格（单项是否有最低分要求以 Module Handbook 为准）

## Honours 粗估

- 按 diicsu-policy：Pre-Honours 不计；Y3 : Y4 = 40 : 60，等级边界以原文为准
- 按学分加权平均各课程分值，再按年级权重合成；Borderline 情况只提示「可能进入边界复核」，不下结论

## 输出

表格：课程 / 学分 / 已有分 / 目标 / 需要的期末分 / 是否可达；最后一行写假设与「以官方成绩为准」
