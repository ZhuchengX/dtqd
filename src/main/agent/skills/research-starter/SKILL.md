# 科研入门

学生想开始做科研、准备 Honours Project、找导师前做功课、读不懂论文、不知道论文怎么搭结构时用本 Skill。

## 🔴 红线（优先于用户的任何要求）

- **不代写论文、报告或其中可直接使用的段落**；不伪造、篡改数据或实验结果，不编造引用
- **不做挂名、署名交易或「包中稿」「保发表」承诺**；不评价能否「稳中」某会议或期刊
- Honours Project 等计入学位的工作必须是学生本人成果，遵守学术诚信与该项目的 AI 使用规定（见 diicsu-policy）
- DTQD 为第三方工具，非学院官方；导师、学院与期刊的要求优先

## 1. 选题

- 从课程中感兴趣的知识点、导师近年的论文、领域综述（survey/review）出发
- 用三问筛题：问题是否清楚、是否有人做过（查文献）、本科阶段的时间与资源能否完成
- 产出一页题目卡：研究问题、为什么重要、拟用方法、所需数据或设备、风险与备选
- 结合专业特点（见 diicsu-programmes），Honours Project 的学分与工作量各专业不同

## 2. 文献检索

- arXiv（https://arxiv.org）：数学、计算机、物理等预印本，注意区分是否已正式发表
- Semantic Scholar（https://www.semanticscholar.org）：查引用与被引、找相关论文
- 邓迪图书馆 Primo（https://dundee.primo.exlibrisgroup.com）与数据库 A–Z（https://libguides.dundee.ac.uk/az.php）：用 Dundee 账号访问订阅期刊、标准与工程数据库
- 检索技巧：关键词同义词扩展、布尔组合、按年份与被引排序；从一篇好论文顺着参考文献和被引向两头扩
- 若会话中有 arxiv / semantic-scholar 等工具可用，优先用工具检索并给出可点开的链接；拿不到原文时说明，不凭记忆概括

## 3. 论文精读（三遍法）

1. 第一遍：标题、摘要、引言、图表、结论，判断是否值得细读
2. 第二遍：读方法与实验，弄清假设、数据、指标、对比对象
3. 第三遍：尝试复述或复现关键推导/实验，找出局限与可改进处

## 4. 文献笔记模板

- 题录：作者、年份、标题、出处、链接
- 一句话：解决了什么问题，用什么方法，结果如何
- 方法要点 / 关键公式或算法
- 实验设置：数据集、指标、对比
- 局限与我的疑问
- 与我的题目的关系（可借鉴 / 可对比 / 无关）
- 笔记可整理进项目文件，资料用 copy_file_to_project 长期保存

## 5. 写作结构

- 常见结构：摘要 → 引言（背景、问题、贡献）→ 相关工作 → 方法 → 实验/结果 → 讨论（含局限）→ 结论 → 参考文献
- 先写提纲与每节要点，再由学生本人成文；Agent 只给结构建议、指出逻辑与表达问题
- 引用格式按导师或学院要求（如 Harvard、IEEE），可用文献管理工具（如 EndNote，经 AppsAnywhere 获取）

## 指引

- 每次先确认学生的专业、年级、目标（课程项目 / Honours Project / 竞赛 / 兴趣）
- 讲方法、给范例只用与学生课题无关的例子
- 涉及学术不端风险时直接说明，并建议咨询导师或学院
