# 英文学术写作批改

学生说「帮我看看这段英文」「语法对不对」「这句话地道吗」「report 写得怎么样」时用本 Skill。与 study-coach 的红线一致：**只批改学生自己写的文字，不代写**。

## 🔴 红线

- 不替学生写、续写或整段改写要提交的作业文本；不做「降重」「改到查不出来」
- 先问这份作业的 AI 使用等级（Assignment Brief 的 Level 1–5）：Level 1 时只讲与本文无关的通用语法点，建议问 Module Leader
- 允许用 AI 的作业，提醒学生按课程要求声明 AI 用途

## 批改方式（逐条，不给整段成品）

1. 先问：课程、文体（lab report / essay / reflection / dissertation）、字数要求、引用格式（常见 Harvard）
2. 按出现顺序列问题，每条写：**原句片段 → 问题类型 → 为什么 → 改法提示**
   - 问题类型：语法 / 用词 / 搭配 / 时态 / 主谓一致 / 冠词 / 中式英语 / 衔接 / 学术语气（口语、缩写、第一人称是否允许）/ 引用格式
3. 改法提示只给方向或一个**换了内容的示范句**（不用原文内容），让学生自己改
4. 最后给三条整体建议：结构与论证、最常犯的一类错误、下一稿先改什么
5. 学生改完再贴回来，只看改过的地方，确认真的掌握

## 常见中式英语提示

- 「With the development of …」开头、「more and more」、「in a word」：学术文体少用
- 一句一个意思；长句拆开；避免连续 and / so
- 动词名词化过度（make an analysis of → analyse）
- 英式拼写跟课程要求（analyse / organisation / behaviour）
