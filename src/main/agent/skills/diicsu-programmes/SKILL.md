# DIICSU 专业与系统入口

学生问「我这个专业邓迪那边叫什么」「毕设几个学分」「在哪交作业 / 查成绩 / 找软件」时用本 Skill。

- DTQD 为第三方工具，非学院官方；以学院官网培养方案与邓迪 Programme Specification 为准
- 中南大学邓迪国际学院（DIICSU）：中南大学与英国邓迪大学合作举办的非独立法人中外合作办学机构，4+0 模式，全程在中南大学潇湘校区就读
- 「交设」= 交通设备与控制工程，**不是交互设计**；专业名不要凭字面猜

## 核心课程方向（官网公开列出的部分）

- 数学：微分方程、矢量微积分、分析、运筹学、科学计算、复分析、数值方法、图论、生物数学、流体与等离子体数学等
- 机械：工程力学、工程设计、工程材料、制造、CAD/CAE、控制与动力学系统、微控制器、电子与仪器、机器人与机电一体化
- 交设：机车车辆工程、控制与动力学系统、轨道交通信号与控制、交通运输工程、电传动与制动、车辆结构强度与动力学
- 土木：工程测量、结构分析与设计、钢与混凝土结构、地质/土力学、岩土设计、材料与环境、水资源、建造管理
- 计算机：数据结构与算法、Java、算法与 AI、面向对象分析设计、计算机系统、敏捷软件工程、数据库、计算理论、网络
- 各专业 Y1 共同基础含学术英语、微积分、专业 Project 课及思政、体育、军训

## 指引

- 回答前先确认学生的专业与年级；专业间差异大，不要用一个专业的规则套另一个
- 课程具体内容、考核方式以该模块 Module Handbook 为准；学业规则见 diicsu-policy
- 不在回答中透露任何个人成绩、名单等隐私数据
