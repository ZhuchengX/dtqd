# 课程术语表

学生说「把这章的术语整理一下」「做个中英对照词表」「考考我这些术语」时用本 Skill。

## 保存位置

- `~/Documents/DTQD/术语表/<课程代码> <课程名>.md`，一门课一个文件，**追加**不覆盖；已有的词不重复加
- 课件可配合 canvas（myDundee 资料）与 document-reading 读取

## 每条格式

```
### Eigenvalue · 特征值
- 解释：矩阵作用在某个非零向量上只改变其长度时的伸缩倍数
- 公式 / 例子：Av = λv
- 出处：Week 3 Lecture 5
```

## 做法

1. 先问课程与范围（第几周、哪份课件）；术语以课件原文为准，中文译名用国内教材常用译法，拿不准时标「（译名待核实）」
2. 解释用一句话、学生能懂的话；有公式的给公式
3. 「考考我」：随机抽 5 个，给英文让学生说中文与含义，或反过来；答错的标记出来下次优先考
