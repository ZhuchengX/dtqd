# QQ / 微信接收文件

DIICSU 的辅导员通知、期末考试安排等常发在 QQ 群（其次微信群）。群里的文件下载后落在本机接收目录，本 Skill 只读这些文件，**不读聊天记录、不解密任何数据库**。

## 命令（Bash 内 dela）

- `dela list_chat_files '{}'`：最近 14 天收到的文件（QQ + 微信），按时间倒序
- `dela list_chat_files '{"app":"qq","days":30,"query":"考试"}'`：按应用、天数、文件名关键词筛选
- 返回的 `path` 是本机绝对路径：PDF/Office 用 document-reading Skill 读正文；需要长期保存时用 shell 复制进对应课程项目

## 指引

- 只列出「已下载」的文件；群文件没点下载时不会出现在这里，提醒学生先在 QQ/微信里点开或下载
- 归档建议：按课程放进项目的 `资料/` 目录，文件名保留原名，前面加日期（如 `2026-10-31_期末考试安排.xlsx`）
- 考试安排、截止通知读完后，用 todo / curriculum 的命令写进待办与日历
- `roots` 为空：说明本机没找到 QQ/微信接收目录（Windows 路径因安装位置不同可能不同），请学生告诉你文件实际所在文件夹
- 通用：`dela help` 查看全部命令与参数
